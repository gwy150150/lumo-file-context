Lumo 1.2.1 · 文件版
=====================================

一、这是什么
-------------------------------------
在 Lumo 1.0.0 便携版基础上改的版本，新增：
  1. 「添加文件」：把本地文件作为上下文发给模型，模型依据文件内容回答问题
  2. 「自定义数据目录」：聊天记录和配置可以放在任意磁盘，随时切换

原版 exe 没有动过，可以继续保留。


二、怎么用（三步）
-------------------------------------
1. 把整个「Lumo-1.2.0-文件版」文件夹放到任意位置。
2. 把你原来 Lumo 目录里的 LumoData 文件夹（含 lumo-data.json，存着模型配置和聊天记录）
   整个复制到新文件夹里，跟 Lumo.exe 放在同一层；不复制也行，那就重新配置一次 API Key。
3. 双击 Lumo.exe 启动。


三、添加文件
-------------------------------------
· 点输入框左下角的「添加文件」（回形针图标）→ 选一个或多个文件
· 直接把文件从资源管理器拖进窗口，出现蓝色虚线提示框后松手
· 复制文件后在输入框 Ctrl+V，也能当附件加上
· 附件的类型、文件名、大小、字符数会显示成标签，右侧 × 可移除
· 可以只发文件不打字，也可以带上问题（如「这份合同的违约责任是什么？」）
· 发出去后文件标签会留在你的消息下面，方便回看当时带了什么

支持：PDF、Word(.docx)、Excel(.xlsx)、PPT(.pptx)、TXT、Markdown、CSV/TSV、JSON、XML、
      YAML、LOG、INI，以及常见源码文件；中文支持 UTF-8 / UTF-16 / GBK 自动识别。

限制：
  · PDF 是尽力解析，扫描件、纯图片 PDF 读不出文字（会显示红色警告）
  · 旧格式 .doc / .xls / .ppt 不支持，请另存为新格式
  · 图片不做 OCR，只记文件名
  · Excel 每表最多取 3000 行；单文件最多 20 万字符，超出截断并提示
  · 文件正文会存进本地 lumo-data.json；发给云端 API 就等于把内容交给该服务商，
    涉密文件建议走本地 Ollama


四、把数据放到别的盘（1.2.0 新增）
-------------------------------------
设置 → 数据：

  · 更改目录：选一个文件夹（例如 D:\Lumo），数据会存到 <所选文件夹>\LumoData
  · 打开目录：在资源管理器里打开当前数据目录
  · 恢复默认：回到 exe 同级的 LumoData

切换立即生效，不需要重启；现有 lumo-data.json 会自动复制到新位置，界面数据同步刷新。
自定义路径记录在 exe 同级的 lumo-data-dir.txt；如果那个磁盘以后不可用（拔掉 U 盘、
盘符变了），会自动回退到 exe 同级的 LumoData 正常启动，不会打不开。

小提示：想让配置完全跟着 U 盘走，就把整个程序文件夹放到 U 盘，数据目录留在默认位置即可。


五、相对原版的改动（技术细节）
-------------------------------------
1. 新增 src/main/files.js：纯 Node 实现的解析器（自写极简 ZIP 读取，无第三方依赖），
   处理 docx / xlsx / pptx / pdf / 文本，含编码识别与二进制探测。
2. src/main/main.js：
   · 新增 file:pick（系统选择框）、file:extract（接收拖拽/粘贴的二进制）两个 IPC
   · 新增 data:choose-dir / data:reset-dir / data:open-dir 三个 IPC
   · 数据目录运行期可切换（activeDataDir），不必重启
   · 其余：便携数据目录双重兜底（PORTABLE_EXECUTABLE_DIR → exe 同级）
3. src/main/preload.js：暴露 pickFiles / extractFile / chooseDataDir / resetDataDir / openDataDir
4. src/renderer/index.html + styles.css：附件区、回形针按钮、拖拽遮罩、数据目录按钮组
5. src/renderer/app.js：
   · 附件状态管理与标签渲染（含警告样式）
   · 发送时拼接「【文件 N：文件名】+ 正文」上下文块
   · 消息对象新增 attachments（元信息）与 apiContent（真正发送的内容）
   · 拖拽 / 粘贴 / 只发文件的可发送判断
   · 切换目录后重新加载并刷新界面


六、想改回去 / 自己再改
-------------------------------------
· 回到原版：直接用原来的 Lumo-便携版-1.0.0.exe，本版没改系统任何设置。
· 自己改代码：源码在 resources\app\src，未压缩的明文 JS，改完重启 Lumo.exe 就生效。
· resources 下已没有 app.asar，改成了 app 目录；若要把 app.asar 放回来，记得先删掉 app 目录。

七、双击没反应怎么办
-------------------------------------
症状：双击 Lumo.exe 后什么都没发生，没有窗口、也没有任何报错。

原因：Lumo 是单实例程序。若后台残留了旧进程（上次关窗口时没退干净），它会一直
      占着"单实例锁"，此后每次双击，新进程都直接静默退出（退出码 0），
      所以既没窗口也没提示。这不是被杀毒软件拦截。

处理：
  1. 任务管理器里找到所有 Lumo.exe，全部"结束任务"
  2. 再双击 Lumo.exe 一次

1.2.1 已修复这个体验问题：
  · 再次双击时若检测不到窗口，会自动重建窗口
  · 窗口 3 秒内没能显示出来会强制显示
